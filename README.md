# Role-Based Authentication System

A full-stack role-based authentication and authorization system built with React, TypeScript, FastAPI, and PostgreSQL.

## Project Objective

The application provides secure authentication and role-based authorization for users with different access levels.

## Initial Roles

- ADMIN
- MANAGER
- USER

## Technology Stack

### Frontend

- React
- TypeScript
- Vite
- Material UI
- Redux Toolkit
- React Hook Form
- Zod
- Vitest
- React Testing Library

### Backend

- Python
- FastAPI
- Pydantic
- SQLAlchemy
- Alembic
- JWT

### Database

- PostgreSQL

## Architecture

The initial application will be developed as a modular full-stack application.

The frontend will initially be developed as a single React application with clear feature boundaries.

After the application is completed and stabilized, the frontend may be evolved into a Micro-Frontend architecture.
